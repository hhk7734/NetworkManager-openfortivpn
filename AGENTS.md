# AGENTS.md

## Security

This repository is public. In code, docs, commits and pull requests:

- Do not include private information: real IP addresses, hostnames,
  usernames, secrets or debugging output from a real machine.
- In examples, use `192.0.2.0/24`, `2001:db8::/32` and `example.com`.

## Language

- Write English at CEFR B2 level: short sentences and common words.
